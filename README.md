# Eurokoder, standarder og regelverk

**Nettside:** <https://stigsam.github.io/eurokoder-standarder-regelverk/>

En samleside for å holde seg orientert om endringer i kodeverk og standarder som er relevante for byggingeniører. Siden er laget for undervisning og faglig orientering ved Høgskulen på Vestlandet.

## Hva siden viser

- **2. generasjon eurokoder (EN 1990–1999):** status for hver del, utgivelse som norsk førstandard (SN-EN) og nasjonale tillegg
- **Milepæler:** felles europeisk tidsplan og norsk innføring, med nedtelling til 1. generasjon trekkes tilbake
- **Hva endres:** de viktigste faglige endringene i 2. generasjon, med filter på type endring og eurokode
- **Kommende endringsblad** og **nye eurokoder** utover EN 1999 (glass, FRP, membraner, tre–betong-samvirke)
- **Norsk regelverk og overgang:** hva som gjelder i prosjekteringen før og etter overgangen
- **Andre standarder og regelverk:** TEK17 og andre forskrifter, sentrale NS-standarder og Kartverkets standarder for geografisk informasjon, med filter og søk

Nederst på siden, under «Kilder og datagrunnlag», står hvor opplysningene kommer fra og når hver kilde sist ble oppdatert. Datafilene kan også lastes ned derfra.

## Hvor oppdatert er siden?

Innholdet kontrolleres mot kildene en gang i måneden. Datoen for siste kontroll står øverst på siden. Er dataene eldre enn 90 dager, vises en advarsel.

Siden er en oversikt og erstatter ikke kildene. Sjekk alltid gjeldende utgave hos [Standard Norge](https://online.standard.no), [DiBK](https://www.dibk.no) eller [Geonorge](https://www.geonorge.no) før du bruker noe i prosjektering, undervisning eller veiledning.
